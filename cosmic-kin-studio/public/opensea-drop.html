    Sequential onchain token IDs are supported. Public artwork is shuffled locally once and held in the upload manifest for delayed reveal. This is standard reveal preparation, not verified randomness; the creator knows the mapping. The earlier D20DAO request-and-claim flow is retired.

    The local upload candidate contains 7,777 images and a CSV using tokenID, name, description, file_name and attributes[Trait].     OpenSea Studio can publish uploaded artwork and metadata to IPFS during reveal. A separate Pinata subscription is not required for that managed workflow.
